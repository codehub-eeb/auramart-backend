# AuraMart – Backend

### Backend API for a Full Stack E-Commerce Application

AuraMart is a full-stack e-commerce application designed to provide users with a modern and seamless online shopping experience.

This repository contains the backend implementation of AuraMart, responsible for handling server-side operations, API requests, business logic, and database interactions.

## Features

JWT Authentication – Secure user authentication using JSON Web Tokens.
Protected Routes – Restrict access to authorized users.
Token-Based Authorization – Verify user identity through JWT tokens.
RESTful APIs – Handle frontend-backend communication.
MongoDB Integration – Store and manage application data.
Server-Side Logic – Handle backend operations and business logic.
E-Commerce Functionality – Support the AuraMart shopping experience.

## Tech Stack

- **Node.js** – JavaScript runtime environment.
- **Express.js** – Backend web framework.
- **MongoDB** – NoSQL database.
- **JavaScript** – Backend programming language.
- **Git & GitHub** – Version control.

## Installation & Setup

Follow these steps to run the backend locally.

**1. Clone the repository**

```bash
git clone https://github.com/codehub-eeb/auramart-backend.git
```

**2. Navigate to the project directory**

```bash
cd auramart-backend
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create a `.env` file in the root directory and add the required configuration.

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
```

Use the actual variable names expected by your backend code.

**5. Start the server**

Run the start command configured in your `package.json`.

```bash
npm start
```

For development, use `npm run dev` if a development script is configured.
